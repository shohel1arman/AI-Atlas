What just happened

The identity kernel copies the image straight through — its centre weight is 1 and everything else is 0.

Kernels & feature maps

One kernel produces one feature map. A conv layer learns dozens of kernels in parallel, each firing on a different pattern — early layers find edges and colour blobs, deeper layers compose them into textures, parts, then whole objects.

Stride & padding

Stride is how far the kernel jumps each step; stride 2 halves the output size. Padding rings the input with zeros (or edge values) so output can keep the input's size — this demo uses edge padding at the borders.

Pooling & receptive field

Max/avg pooling downsamples, adding translation tolerance. Stacking convs grows the receptive field — a deep neuron "sees" a large patch of the original image even though each kernel is tiny.

Weight sharing

The same kernel weights are reused at every position. That's translation equivariance — an edge is an edge anywhere — and it slashes parameters versus a dense layer, the key idea that makes CNNs trainable on images.

CNN architectures

LeNet-5 (1998) read digits; AlexNet (2012) won ImageNet and lit the deep-learning era; VGG stacked 3×3 convs; ResNet added skip connections to train 100+ layers; EfficientNet scaled depth/width/resolution together.

Transfer learning

A network pretrained on millions of ImageNet images already knows generic edges and textures. Freeze those layers, swap the final head, and fine-tune on your small dataset — state-of-the-art results with a fraction of the data and compute.

Scoring a detector

A prediction counts as a true positive when IoU ≥ a threshold (often 0.5). From there: precision = TP / (TP+FP), recall = TP / (TP+FN). Sweep the confidence threshold to trace a precision–recall curve; its area is Average Precision. Mean AP over all classes is mAP — the headline COCO metric, reported as mAP@[.5:.95].

Sliding window → R-CNN

The brute-force start: slide a classifier over every window and scale. R-CNN made it tractable by classifying ~2000 region proposals instead of every window — accurate but slow.

Fast / Faster R-CNN

Fast R-CNN ran the CNN once and pooled features per region. Faster R-CNN replaced external proposals with a learned Region Proposal Network, making the whole pipeline end-to-end.

One-stage: YOLO & SSD

YOLO and SSD skip the proposal stage — one forward pass predicts boxes and classes on a grid. Two-stage detectors trade speed for precision; one-stage trade the reverse and run in real time.

Anchors & NMS

Anchor boxes are preset shapes at each grid cell; the net predicts offsets from them. Many overlapping boxes survive, so Non-Max Suppression keeps the highest-confidence box and discards its high-IoU neighbours.

Real models replace this crude threshold with a learned per-pixel classifier — but the output shape is the same: a class label for every pixel.

Semantic

Every pixel gets a class — "road", "car", "sky" — but two cars of the same class merge into one blob. It answers what, not which.

Instance

Separates individual objects — car #1 vs car #2 — but usually ignores amorphous "stuff" like sky or grass. It answers which.

Panoptic

The unification: every pixel gets a class and countable "things" get instance IDs. Semantic + instance in one coherent output.

Segmentation architectures

FCN made classification networks fully convolutional to output dense maps. U-Net added an encoder–decoder with skip connections that carry fine detail across the bottleneck — dominant in medical imaging. DeepLab uses atrous (dilated) convolutions to widen the receptive field without losing resolution. Mask R-CNN extends Faster R-CNN with a mask branch for instance segmentation.

Vision Transformers & beyond

The Vision Transformer (ViT) drops convolution entirely. It cuts the image into fixed patches (e.g. 16×16), flattens each into a token, adds a positional embedding, and feeds the sequence to a standard Transformer. Self-attention lets every patch attend to every other patch, giving a global receptive field from layer one — where a CNN needs depth to see globally.

image → patchify (16×16) → flatten → + position → tokens → self-attention × L → class / dense head

DETR reframes detection as set prediction: a Transformer decoder emits a fixed set of boxes with bipartite matching, removing anchors and NMS. SAM (Segment Anything) is a promptable foundation model that segments any object from a point or box click, zero-shot.
