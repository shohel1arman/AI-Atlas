A Markov Decision Process is the world an agent lives in: states, actions, a reward for each move, and a discount γ that trades off now versus later. Value iteration repeatedly applies the Bellman equation — the value of a cell is the best action's reward plus the discounted value of where it lands — until values stop changing. The arrows are the greedy policy that falls out.

In value iteration the agent knew the whole map. Q-learning is model-free: the agent knows nothing, and learns action-values Q(s,a) purely by trial and error over many episodes. Each step nudges its estimate toward reality — the temporal-difference update. Run episodes and watch a good path light up on the same grid.

TD learning

Q-learning bootstraps: it updates a guess from a slightly better guess, one step at a time — no need to reach the end of an episode.

Off-policy vs SARSA

Q-learning is off-policy — it learns the greedy value while exploring. SARSA is on-policy: it learns the value of the policy it actually follows.

Deep RL

Replace the table with a neural net and you get DQN (replay buffer, target network). Policy-gradient methods — REINFORCE, A2C, PPO — optimise the policy directly.
