JSON mode & tools

Modern APIs offer a JSON/response-format mode and function-calling so the model returns arguments matching a schema you define.

Delimiters

Wrap inputs in triple backticks or tags so the model can't confuse instructions with data — a key defence against prompt injection.

Ground & cite

For RAG, tell the model to answer only from provided context and cite sources; instruct it to say "I don't know" when the context is silent.
